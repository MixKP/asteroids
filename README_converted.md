# Asteroids
## Project Overview
This project is a part of **SE233 Advance Programming** course 
The objective is to replicate the classic arcade game **Asteroids** using Java.

## Gameplay
- **Objective**: The player's goal is to shoot and destroy asteroids to earn points. The game ends when the player loses all lives.
- **Controls**:
  - **Move Left**: A
  - **Move Right**: D
  - **Move Forward**: W
  - **Move Backward**: S
  - **Rotate Left**: Q
  - **Rotate Right**: E
  - **Shoot**: SPACE
  - **Special shoot**: R
  - **Random Warp**: SHIFT
